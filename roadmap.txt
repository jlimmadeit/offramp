how flowstage works is you create video aesthetics, which are folders of audio snippets, videos and text hooks. These ultimately pair up with editing styles and create a finalized video. 

Build an n8n-style draggable node canvas workflow editor for automating content creation and distribution for TikTok, using React, TypeScript, Vite, Tailwind CSS, and React Flow (@xyflow/react). The app is called "Flowdify."

Design system: Apple/Jony Ive-inspired. White node cards on a light gray #F5F5F7 canvas. Apple system font stack. Bold 13px semibold sentence-case titles. Subtle shadows for depth instead of borders. Apple system accent colors per node type (purple, teal, orange, blue, indigo, red). No gradients, no dark mode, no neon glows. Clean, minimalist, bright, confident.

Sidebar (left):

Logo area with "Flowdify" branding
Collapsible "Nodes" section listing all 6 draggable node types. Drag from sidebar onto canvas to create new nodes.
Collapsible "Video Bucket" section where users can upload or drag-drop video files (under 60 seconds). Uploaded files show thumbnails, durations, and are draggable onto nodes.
Node types:

Videos (purple #AF52DE) — Accepts video file drops from the file bucket. Displays videos in a 3-per-row square grid (like Apple Photos app). Grid is scrollable. Each cell shows thumbnail with play/pause overlay on hover, duration badge, and remove button.

Audio Snippets (teal #5AC8FA) — Displays audio data from Flowstage with sections and lyric lines. Expandable/collapsible sections showing timestamps and lyrics. Scrollable list.

Text Hooks (orange #FF9500) — Has an input field to add text hooks. Shows hooks in a numbered, expandable/collapsible, scrollable list with remove buttons.

Edit Style (indigo #5856D6) — Shows pace, mood, and transition tags as colored pills. Has a small beat visualizer bar chart. Output handle on the right connects to Aesthetic's left "editStyle" handle.

Aesthetic (blue #007AFF, green #34C759 when complete) — Central combining node. Has 4 input handles on the left (editStyle, clips, audio, text) and 1 output handle on the right. Shows slot rows for each input that light up when connected, with count indicators (e.g., "3/5"). Status light: red when incomplete, green when all conditions are met. Footer shows "X/4 ready." Conditions for green: 5+ clips connected, 1+ audio connected, 1+ text hook connected, 1+ edit style connected.

Account (red #FF3B30, green #34C759 when connected) — Shows username, @handle, follower count, and platform badge (TikTok/Instagram/YouTube). Input handle on the left. Turns green when an Aesthetic connects to it.

All nodes share a NodeShell wrapper providing:

Collapse/expand via chevron dropdown (body hides but edges/connections stay visible because handles are always rendered)
Inline rename on double-click
Save preset button and load preset dropdown (except Account nodes)
Consistent white card styling with shadow elevation and accent-colored icon pill
Connection rules (enforced via isValidConnection):

Videos → Aesthetic (clips handle only)
Audio Snippets → Aesthetic (audio handle only)
Text Hooks → Aesthetic (text handle only)
Edit Style → Aesthetic (editStyle handle only)
Aesthetic → Account (in handle only)
No other connections allowed
Aesthetic collapse animation: When the Aesthetic node is collapsed, all connected source nodes (Content/Clips, Audio, Text Hooks, Edit Style) animate flying into the Aesthetic's position and fade out, then hide. When expanded, they animate back out from the Aesthetic to their original saved positions. Edges to hidden nodes hide automatically.

Scrolling: Internal scrollable lists within nodes (videos grid, audio list, text hooks list) use React Flow's nopan nodrag nowheel classes so scrolling works without triggering canvas panning/zooming.

State management: React Context (WorkspaceContext) manages global file bucket and presets. Asset counts from source nodes propagate to connected Aesthetic nodes in real-time so the green/red status updates as videos is added or removed.

================================================================================
Goal: All 6 node types render on the canvas, can be dragged from the sidebar to

  a) <NodeShell /> wrapper component
     - White card, shadow, accent-colored icon pill (color from kind_id)
     - Collapse/expand chevron (body hides, handles stay rendered)
     - Double-click title → inline rename → PATCH nodes.name
     - Save/Load preset buttons (UI only — no preset table yet, show toast
       "presets coming soon")

  b) 6 node type components, each wrapped in <NodeShell />
     - <VideosNode />      — empty grid placeholder, purple accent
     - <AudioNode />       — empty list placeholder, teal accent
     - <TextHooksNode />   — input + empty list, orange accent
     - <EditStyleNode />   — static pace/mood/transition pills, indigo accent
     - <AestheticNode />   — 4 input handles (editStyle, clips, audio, text),
                             1 output handle, slot rows, status light, footer
     - <AccountNode />     — username/@handle/followers/platform badge,
                             1 input handle, red accent

  c) Sidebar → Canvas drag-to-create
     - "Nodes" section lists all 6 kinds (from node_kinds in context)
     - onDragStart sets transfer data with kind_id
     - Canvas onDrop: INSERT into nodes (name, x_position, y_position, kind_id)
       → Supabase returns the new row → add to React Flow state

  d) Position persistence
     - onNodeDragStop: UPDATE nodes SET x_position, y_position WHERE id = ?
     - Debounce 300ms so rapid drags don't spam the API

  e) Load existing nodes on mount
     - SELECT * FROM nodes (with kind_id) → map to React Flow nodes
     - JOIN node_kinds to resolve display_name for the icon pill

  f) Deliverable checkpoint
     - Drag any of the 6 node types from sidebar onto canvas
     - Nodes persist across refresh (positions + names saved in Supabase)
     - Rename works, collapse/expand works
     - No edges yet, no file bucket, no media inside nodes

  Tables touched: nodes (CRUD), node_kinds (read)

================================================================================
STEP 3 — Edges, Connection Rules & Aesthetic Status
================================================================================
Goal: Users can draw edges between nodes following the allowed connection rules.
      The Aesthetic node's status indicator reacts in real-time. Edges persist.

  a) Connection rules (isValidConnection callback)
     - Videos       → Aesthetic (clips handle only)
     - Audio        → Aesthetic (audio handle only)
     - Text Hooks   → Aesthetic (text handle only)
     - Edit Style   → Aesthetic (editStyle handle only)
     - Aesthetic    → Account   (in handle only)
     - All other attempts rejected (return false, brief shake animation on
       the target handle)

  b) Edge creation
     - onConnect: INSERT into currents (from_node_id, to_node_id)
     - Edge styling: 1.5px solid, color = source node accent, opacity 0.6
     - Animated dash on hover via CSS

  c) Edge deletion
     - Right-click edge → "Remove" context option
     - DELETE FROM currents WHERE id = ?

  d) Load existing edges on mount
     - SELECT * FROM currents → map to React Flow edges
     - Resolve source node kind_id to set edge color

  e) Aesthetic node real-time status
     - When an edge connects/disconnects, recompute for each Aesthetic node:
       - Count inbound edges by source kind via currents + nodes join
       - For "clips" connections: sum node_videos count for each connected
         Videos node (SELECT count(*) FROM node_videos WHERE node_id IN (...))
       - For "audio": sum node_audios count
       - For "text": sum node_text_hooks count
       - For "editStyle": count connected Edit Style nodes (1+ needed)
     - Status light: red (#FF3B30) when incomplete, green (#34C759) when all
       conditions met (5+ clips, 1+ audio, 1+ text, 1+ edit style)
     - Footer: "X/4 ready" updates in real-time
     - Account node turns green when it has an inbound edge from Aesthetic

  f) Deliverable checkpoint
     - Draw valid edges between nodes — invalid combos rejected
     - Edges persist across refresh
     - Aesthetic status light and count indicators update live as
       connections are added/removed
     - Deleting an edge updates Aesthetic status immediately

  Tables touched: currents (CRUD), nodes (read — kind resolution),
                  node_videos (read — clip count), node_audios (read — audio
                  count), node_text_hooks (read — text hook count)
